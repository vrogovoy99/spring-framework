1. Add OpenFeign dependency

1.1. add common property version for all cloud components by adding pom properties section:

        <spring-cloud.version>2.2.6.RELEASE</spring-cloud.version>

1.2. add Open Feign dependency using common property

        <dependency>
            <groupId>org.springframework.cloud</groupId>
            <artifactId>spring-cloud-starter-openfeign</artifactId>
            <version>${spring-cloud.version}</version>
        </dependency>

2. Enable Feign services by adding @EnableFeignClients annotation in runner classes

3. Add Feign client api call in clint package

4. Keycloak

4.1. create docker-compose.yaml to download and deploy keyclock container.
4.2. start docker locally
4.3. Run at the file location: docker compose up
    (the docker will download keylock and run it. it can be accessed at localhost:8080)
4.4. In Keyclock portal create:
4.4.1. client master-client (in master realm)
4.4.2. realm: cydeo-dev
4.4.3. client: ticketing-app (in cydeo-dev realm) Enable client authentication during the creation.
4.4.4. open ticketing-app client details > Credentials > copy Client secret > paste it in all applications yaml files.

4.4. to upload users into keycloak add keycloak-legacy-user-loader app,
4.4.1. update application yml file to connect to our running keycloak app
4.4.2. Add roles in keycloak: cydeo-dev realm > clients > ticketing-app > roles : create roles Admin, Manager, Employee
4.4.3. after completing setup - run keycloak-legacy-user-loader app to load data.sql  users into keycloak database.

6. Use API call in the code.
6.1. @FeignClient in com/cydeo/client/ProjectClient.java interface will create a bean
6.2. We insert reference to this bean in com/cydeo/service/impl/UserServiceImpl.java and use its API call function in checkManagerConnections method.

7. API call security > passing a authorization token
7.1. com/cydeo/service/impl/KeycloakServiceImpl.java and KeycloakService interface add getAccessToken method to extract and return authorization string from request security context
7.2. add @RequestHeader(value = "Authorization") in com/cydeo/client/ProjectClient.java and TaskClient API calls to pass authorization token
7.3. in com/cydeo/service/impl/UserServiceImpl.java where the API are called add Autorizaton extract method and pass it to API call
7.*. To avoid above steps 7.2 and 7.3 and replicate code in case of every API call add custom RequestInterceptor com/cydeo/client/interceptor/FeignClientInterceptor.java
    that will automatically add authentication token to every API call.

8. EUREKA - Service Discovery registers microservice address.
******************** SERVER ********************
NOTE: presented server changes did not work. look into pom.xml and application.properties in discovery-service to make Eureka work.
8.1. Generate project in https://start.spring.io/:
    Project: Maven
    Language: Java
    Group: com.cydeo
    Artifact: discovery-service
    Click on Generate, download project, extract it from zip into designated location.
8.2. Add Eureka Server to discovery project.
8.2.1. in discovery-service project pom.xml add dependency:
            <dependency>
    			<groupId>org.springframework.cloud</groupId>
    			<artifactId>spring-cloud-starter-netflix-eureka-server</artifactId>
    			<version>${spring-cloud.version}</version>
    		</dependency>
    where spring-cloud.version should be added in properties section.
8.2.2. In project runner class add annotation: @EnableEurekaServer
8.2.3. add eureka configuration in application.properties file:
            # default eureka port is 8761
            server:
                port:8761

            # do not register eureka server to the local server (itself)
            # do not request microservice registration information from other eureka servers
            eureka:
                client:
                    serviceUrl:
                        defaultZone: http://localhost:8761/eureka/
                    register-with-eureka: false
                    fetch-registry: false
8.3. RIBBON - Eureka's server side load balancer (will be disabled and client side load balancer will be used)
8.3.1. disable Ribbon in application.properties:
            #disable RIBBON Eureka's load balancer (also to be excluded in pom.xml
            spring.cloud.loadbalancer.ribbon.enabled=false
8.3.2. disable Ribbon in pom.xml > in eureka dependency add three exclusions:
            <dependency>
                <groupId>org.springframework.cloud</groupId>
                <artifactId>spring-cloud-starter-netflix-eureka-server</artifactId>
                <version>${spring-cloud.version}</version>
                <exclusions>
                    <exclusion>
                        <groupId>org.springframework.cloud</groupId>
                        <artifactId>spring-cloud-starter-ribbon</artifactId>
                    </exclusion>
                    <exclusion>
                        <groupId>org.netflix.ribbon</groupId>
                        <artifactId>ribbon-eureka</artifactId>
                    </exclusion>
                    <exclusion>
                        <groupId>javax.servlet</groupId>
                        <artifactId>servlet-api</artifactId>
                    </exclusion>
                </exclusions>
            </dependency>
********************  CLIENT ********************
8.4. Add Eureka client configuration to services
8.4.1. in pom.xml add Eureka client dependency:
            <dependency>
                <groupId>org.springframework.cloud</groupId>
                <artifactId>spring-cloud-starter-netflix-eureka-client</artifactId>
                <version>${spring-cloud.version}</version>
                <exclusions>
                    <exclusion>
                        <groupId>org.springframework.cloud</groupId>
                        <artifactId>spring-cloud-starter-ribbon</artifactId>
                    </exclusion>
                    <exclusion>
                        <groupId>org.netflix.ribbon</groupId>
                        <artifactId>ribbon-eureka</artifactId>
                    </exclusion>
                    <exclusion>
                        <groupId>javax.ws.rs</groupId>
                        <artifactId>jsr311-api</artifactId>
                    </exclusion>
                </exclusions>
            </dependency>
            <dependency>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-starter-jersey</artifactId>
            </dependency>
            <dependency>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-starter-actuator</artifactId>
            </dependency>
8.4.2. in runner class add @EnableDiscoveryClient annotation
8.4.3.a in application.properties add
            #register Eureka server to register this api service
            eureka:
              instance:
            #    IP configuration is optional to avoid long autogenerated server names.
                preferIpAddress: true
                ipAddress: 127.0.0.1
                status-page-url-path: ${management.context-path}/info
                health-check-url-path:  ${management.context-path}/health
              client:
                serviceUrl:
                  defaultZone: http://localhost:8761/eureka/
            # define path to provide Eureka Actuator with the details of this service
            management:
              endpoint:
                health:
                  show-details: "ALWAYS"
              endpoints:
                web:
                  exposure:
                    include: "*"
              context-path: http://localhost:${server.port}/actuator
            # provide Eureka service with details of this api app
            info:
              application:
                name: user-service
                description: Ticketing Application User Service
8.4.3.b in application.properties add application name property, so it can be registered in Eureka and can be recalled.
            spring:
              application:
                name: user-service
8.4.4. Since we are using discovery services instead of direct IP we need to remove url from FeignClient annotation.
            FROM:
                 @FeignClient(value = "project-service", url = "localhost:8082")
            TO:
                @FeignClient(value = "project-service")
