
1. Creating test

1.1. in Calculator.add method > right click > Generate > test

1.2. select JUnit5 and click on FIX button to add dependency in pom.xml

        <dependency>
            <groupId>org.junit.jupiter</groupId>
            <artifactId>junit-jupiter</artifactId>
            <version>RELEASE</version>
            <scope>test</scope>
        </dependency>

1.3. in CalculatorTest class add code to test add method

            @Test
            void add() {
                int actual = Calculator.add(2,3);
            }

1.4. Use assertion methods to define tests:

       assertTrue(Calculator.operator.equals("add"), "Really?");
       assertEquals("adding", Calculator.operator,"Really?");
       assertEquals(5, Calculator.add(2,3), "Expected 5");
       assertArrayEquals(new int[]{1,2,3}, new int[]{1,2,3});
       -- null and not null assertion
          String nullString = null;
          String notNullString = "Cydeo";
          assertNull(nullString);
          assertNotNull(notNullString);
       -- validate if objects are the same (addresses)
       Calculator c1 = new Calculator();
       Calculator c2 = c1;
       assertSame(c1, c2);
       -- assertion throw
       assertThrows(IllegalArgumentException.class, () -> Calculator.add2(5,1));

       -- run method prior/after each case
       @BeforeEach
       @AfterEach
        -- run method prior/after All case (have to be statis methods)
       @BeforeAll
       @AfterAll

       -- parameterized test CalculatorParameterizedTest.java
       @ParameterizedTest
       @ValueSource(strings = {"Java", "JS", "TS"})
            @EmptySource
            @NullSource
            @NullAndEmptySource
       @MethodSource - uses output of other static method as an input for the test method
       @CsvSource({"10,20,30", "20,20,40", "30,20,100"}) - coma separated values
       @CsvFileSource(resources = "/sample-data.csv", numLinesToSkip = 1) - file is stored in src/main/resources
            numLinesToSkip to skip headers in the csv file.
